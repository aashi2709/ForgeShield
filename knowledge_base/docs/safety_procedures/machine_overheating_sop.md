## Purpose

This procedure defines the recommended response when machine temperature readings indicate a potential overheating condition.

## Detection Indicators

Potential overheating may be indicated by:

- Elevated process temperature
- Increasing temperature differential between process and air temperature
- Increased mechanical load
- Unusual operating conditions
- Persistent temperature elevation during operation

## Immediate Response

When overheating is suspected:

1. Assess the machine condition and current operating state.
2. Reduce machine load if this can be performed safely.
3. Inspect the cooling system.
4. Check the process-temperature and air-temperature sensors.
5. Inspect the machine for visible heat-related damage.
6. Follow the applicable site-specific shutdown procedure when continued operation cannot be performed safely.

## Possible Contributing Factors

Potential contributing factors include:

- Reduced cooling effectiveness
- Insufficient heat dissipation
- Extended machine operation
- Increased mechanical load
- Cooling-system degradation
- Sensor problems

These factors are possible explanations and should not be treated as confirmed root causes without further investigation.

## Preventive Measures

Recommended preventive measures include:

- Monitor temperature trends.
- Perform periodic cooling-system inspections.
- Maintain temperature sensors.
- Review preventive-maintenance intervals.
- Monitor machine operating conditions.
