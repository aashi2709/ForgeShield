## Purpose

This procedure defines the recommended response when abnormal machine vibration is detected.

## Detection Indicators

Potential abnormal vibration may be indicated by:

- Increased vibration levels
- Sudden changes in vibration measurements
- Unusual machine movement
- Changes in operating noise
- Persistent vibration during operation

## Immediate Response

When abnormal vibration is suspected:

1. Assess the machine operating condition.
2. Reduce machine load if this can be performed safely.
3. Inspect accessible machine components.
4. Check for loose connections or mounting problems.
5. Inspect relevant rotating components.
6. Follow the applicable shutdown procedure if continued operation is unsafe.

## Possible Contributing Factors

Potential contributing factors include:

- Component wear
- Loose connections
- Misalignment
- Mechanical imbalance
- Bearing or rotating-component problems

These factors are possible explanations and should be verified through appropriate inspection.

## Preventive Measures

Recommended preventive measures include:

- Monitor vibration trends.
- Inspect rotating components periodically.
- Check machine mounting and connections.
- Perform preventive maintenance.
- Investigate persistent changes in vibration behavior.
